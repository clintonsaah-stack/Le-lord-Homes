# Public Assets Directory

Place the following assets in this directory:

## Logo
- `logo.svg` - Main logo (transparent background)
- `logo-dark.svg` - Dark variant for light backgrounds
- `logo-light.svg` - Light variant for dark backgrounds
- `favicon.ico` - Favicon for browser tab

## Images
- `founder.jpg` - Isaac Umoren's professional photograph
- `about-hero.jpg` - About section hero image
- `og-image.jpg` - Open Graph image for social sharing (1200x630px recommended)

## Directory Structure
```
public/
├── logo.svg
├── logo-dark.svg
├── logo-light.svg
├── favicon.ico
├── founder.jpg
├── about-hero.jpg
└── og-image.jpg
```

All images should be optimized for web:
- Use appropriate formats (SVG for logos, JPEG/WebP for photos)
- Compress using tools like TinyPNG or ImageOptim
- Include alt text in components that reference these assets
